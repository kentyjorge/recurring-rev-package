# Skills Reference — recurring-rev-package

Skills relevant to this project. Invoke with a slash command (e.g. `/sf-flow`) or Claude will select automatically based on context.

---

## Primary Skills

| Slash Command | When to Use |
|---|---|
| `/sf-flow` | Edit or extend `RRV_Calculate_Quote_ARR` or `RRV_Run_ARR_Calcs` — decisions, assignments, loops, connectors, Flow XML validation |
| `/sf-metadata` | Add custom fields to Quote or other objects, modify the quick action, create validation rules |
| `/sf-deploy` | Deploy to `main` org, troubleshoot component failures, manage scratch orgs |
| `/sf-permissions` | Update `Admin.profile-meta.xml`, create permission sets, audit field access |

---

## Supporting Skills

| Slash Command | When to Use |
|---|---|
| `/sf-soql` | Query QuoteLineItem fields, verify `BillingFrequency` picklist values, inspect data |
| `/sf-debug` | Analyze Flow debug logs, diagnose runtime errors or wrong ARR values |
| `/sf-testing` | Apex test coverage if Apex is ever added |
| `/sf-diagram-mermaid` | Visualize the flow architecture or field calculation logic |
